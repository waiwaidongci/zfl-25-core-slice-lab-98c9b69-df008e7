# 岩芯切片批次工作台

面向地质实验室技术人员的岩芯切片批次管理工具：样本登记后一次建立多张切片，按
**取样 → 切割 → 研磨 → 染色 → 观察** 顺序推进，每步记录操作人、时间和依据；
工作台展示批次进度、逾期项和下一步负责人，观察结果为空不能交付，重复交付不改写原记录。

## 运行

```bash
npm start        # http://localhost:3025
```

零外部依赖，仅需 Node.js 18+。数据持久化在 `data/core-slice.json`（原子写入），
重启后保留；删除该文件会重新播种演示批次（含逾期、待交付、已交付三种样例）。

## 功能与规则

- **样本登记**：项目 / 钻孔 / 岩芯箱 / 深度 / 登记人，可为五道工序分别指定负责人，
  登记时一次建立多张切片（编号自动生成，如 `B20260912-001-S01`）。
- **批量添加切片**：登记后仍可成批追加；已交付批次封存，不能再加。
- **顺序推进**：每张切片只能推进到唯一的下一工序，请求必须显式给出目标工序（`stage`）；
  每步必须填写操作人与依据，时间可补录（默认当前时间）。非法跳步、回退、重复提交均返回
  `409` 失败提示，状态与历史记录不变。同一张切片针对同一工序的**并发重复请求**（双击、
  网络重试）只允许先到的一个成功，其余返回 `409 duplicate_submit`，不会连续前进两步或多写记录。
- **观察**：进入观察工序必须同时录入观察结果（空白/纯空格拒绝）；未交付前可补录修订，修订追加留痕。
- **交付**：全部切片完成观察且观察结果非空才能交付；交付需交付人与依据。
  重复交付返回 `409 already_delivered` 并回传原交付记录，**绝不改写**；交付后批次只读封存。
- **工作台**：批次进度条（观察完成数/总数）、按工序 SLA 计算的逾期项
  （取样 24h、切割 24h、研磨 48h、染色 24h、观察 72h）、下一步负责人归组。

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/batches` | 工作台总览（进度/逾期/下一步负责人） |
| POST | `/api/batches` | 批次登记（`sliceCount` 或 `slices[]` 一次多片） |
| POST | `/api/batches/:id/slices` | 批量添加切片（`count` 正整数，或非空 `slices[]`；空清单返回 400） |
| POST | `/api/batches/:id/slices/:code/advance` | 推进到 `stage` 指定的目标工序（必填；另含 `operator`/`basis`/`at`，观察时需 `observation`）；并发重复提交返回 409 |
| PUT | `/api/batches/:id/slices/:code/observation` | 观察结果补录修订（留痕） |
| POST | `/api/batches/:id/deliver` | 批次交付（重复交付 409，不改写） |

顺序推进、并发重复提交去重、观察与交付全链路，以及空观察、重复提交、非法跳步/回退、
重复交付防改写、封存只读、SLA 逾期和重启后数据保留。
